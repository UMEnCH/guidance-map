# 面談思考マップ

保健指導の面談で「どの生活習慣に着目し → どこを掘り下げ → どんな情報提供をして → どの目標を立てるか」を、左から右へ枝分かれする樹形図でたどるツール。行動変容ステージ（無関心期〜維持期）ごとの目標例・情報提供文・図説・出典を参照し、ワンクリックでコピーできる。

- 公開: https://umench.github.io/guidance-map/
- HealthGuidanceEvaluator のサイドバー「ツール」と、対象者ビューの「思考マップ」リンクから開く
- 外部ライブラリなし。データはどこにも送信・保存しない

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面（樹形図・詳細パネル・コピー・コードの読み込み） |
| `data/core.js` | 出典の一覧（`GM.SRC`）・判定エンジン |
| `data/01-medication.js` 〜 `data/10-stress.js` | 大項目ごとの収録内容 |
| `data/rules.js` | 対象者に関係する項目の判定ルール |
| `figures/*.svg` | 図説 |

## 収録内容の編集

大項目ファイルの形:

```js
GM.add({ key:'diet_balance', name:'偏食', mids:[
  { id:'fast', name:'早食い', smalls:[
    { id:'fast_eating', title:'早食いは肥満・血糖上昇と関係がある',
      info:'情報提供の本文（\n で改行）',
      figure:'figures/fast-eating.svg', figCap:'図説の説明',
      sources:['program','jds2024'],          // GM.SRC のキー、または {title, pub, url}
      goals:{ '無関心期':[…], '関心期':[…], '準備期':[…], '実行期':[…], '維持期':[…] } } ] } ] });
```

- 中項目を足したら `data/rules.js` に同じ `id` で判定ルールを書く（書かなければ、その中項目は対象者を反映したときに常にグレー）
- 出典は公的機関・学会の資料に限り、URL が開けることを確かめてから `GM.SRC` に足す
- 大項目の `key` は HealthGuidanceEvaluator の生活習慣10項目のキーと同じにする

## 専用コード（HealthGuidanceEvaluator → 思考マップ）

`HGM1.` ＋ JSON を deflate-raw 圧縮して base64url にしたもの。対象者ビューが作り、URL の `#c=` で渡す（ハッシュはサーバーへ送られない）。読み込んだらハッシュは消し、何も保存しない。

```
{v:1, id, sex, dis:[病歴], med:[薬の分類], lab:{bmi:['27.4','high'], …},
 cat:{diet_balance:{o:'問題あり', st:'関心期', pr:'2', it:[['食事スピード','早食いである…'], …]}, …},
 gl:[[2,'exercise','達成','水・日曜日にエアロバイクを20分以上行う'], …],
 ra:[[4,{exercise:['注意','実行期'], …}], …]}
```

`ra` は生活習慣の再評価（第4・8・12回）のうち**確定済みの回だけ**（[回, {大項目キー:[全体評価, ステージ]}]）。

`gl` は面談記録の取り組み内容（[回, 種別キー, 達成状況, 目標の文言(60字まで)]）。達成状況は「達成／目標ライン／変化あり目標未満／変化なし」か、`みなし`（みなし実施の回）・`次回`（次回に向けた新規目標）・空。種別キーは大項目の `key` と同じ（`other`＝10項目外）。

氏名・薬剤名・取り組み状況の詳細メモは含めない（目標の文言だけは、何に取り組んだかを示すために入れる）。作る側は HealthGuidanceEvaluator の `sidebar_person.html`（`guideMapPayload` / `guideMapCode`）、往復の検査は `health-guidance-evaluator/scripts/test_guide_map.js`。

## 判定の見え方

- 左に橙の帯: この対象者に関係あり（理由をチップで表示）
- 点線の枠: 要聴取（「2回目以降の聴取予定」の項目がある）
- グレー: 関係なし（押せば見られる）
- 詳細パネルのステージは、二次情報のステージを初期表示にする
- 大項目は二次情報の優先順位（`pr`）の順に並べ、順位の無いものは「優先順位なし」の区切り線の下に元の順で並べる
- 大項目の左に「生活習慣アセスメント（概略）」の列を出す：全体評価の強さで色分け（大きく問題あり＝赤い面／問題あり＝赤の帯／注意＝橙の帯／要聴取＝点線／問題なし＝薄く）し、判定ルールが拾った問題点（聞き取り項目・検査値・病歴）をチップで表示。押すとその大項目を開く
- 対象者を反映していないときは、概略の列は出さず元の並び
- **取り組み済み**（コードに `gl` があるとき）: 面談の目標に取り上げた大項目・中項目の右に緑の帯と「取組 n」（n＝目標の件数。ホバーで回・文言・達成状況）。大項目へは種別キーで、中項目へは目標の文言が `data/rules.js` の `GM.goalKw` のキーワードに当たったときに割り当てる（種別未設定の目標はキーワードで大項目も決める・`other` は「その他の取り組み」に出す）。概略の列の上に件数と回、各カードに直近3件、大項目を開くと中項目の列の上に「これまでの取り組み」（全件・回・達成状況）
- **次の目標の候補**: 概略の列の上に、要介入（優先順位あり、または いまの評価が注意以上）なのにまだ目標に取り上げていない大項目を、優先順位→評価の重さの順に出す。押すとその大項目を開く。概略カードには「未取組」
- **達成状況の流れ**: 取り組んだ大項目に、回の番号を達成状況の色で並べる（緑＝達成・橙＝目標ライン／変化あり目標未満・赤＝変化なし・点線＝次回から）。確定済みの再評価の回は「再」の四角で挟む
- **再評価**: 確定済みの再評価があれば、概略カードの評価・ステージは最新の回のものにし、「第4回 再評価: ステージ 関心期 → 準備期」のように初回からの変化を出す。詳細パネルのステージの初期表示（「対象者」の印）も最新の回に合わせる
- **過去の目標に近い目標例**: 取り組んだ大項目の小項目で、目標例と過去の目標の近さ（2文字ずつの一致率。言い換えをそろえ、「週◯日以上」などの決まり文句は数えない・`GM.goalSim`。目標は文ごとにも比べて高い方を取る `GM.goalScore`、しきい値 `GM.SIM_TH`=0.4）が高いものに「第2回で実施・達成」の印。小項目には「近い目標」、該当するステージのタブに緑の点
